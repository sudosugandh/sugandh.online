# Business Solutions Website

A modern, professional static React website showcasing end-to-end business solutions. Built with React, Vite, TailwindCSS, DaisyUI, and Framer Motion.

## 🚀 Features

- **Modern React App**: Built with Vite for fast development and optimal performance
- **Professional Design**: Clean, modern UI with TailwindCSS and DaisyUI components
- **Smooth Animations**: Framer Motion animations and transitions throughout
- **Responsive Design**: Mobile-first approach with responsive layouts
- **Static Site**: No backend required, perfect for deployment on any static hosting

## 🚀 Getting Started

### Prerequisites
- Node.js (version 16 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd business-solutions-website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## 📦 Build and Deployment

### Production Build
```bash
npm run build
```

The build files will be generated in the `dist` directory.

### Deployment Options

The website is a static site and can be deployed to any static hosting service:

- **Netlify** - Drag and drop the `dist` folder
- **Vercel** - Connect your Git repository
- **GitHub Pages** - Upload the `dist` folder
- **AWS S3** - Upload to S3 bucket with static website hosting
- **Firebase Hosting** - Deploy using Firebase CLI

## 🔧 Customization

### Colors and Themes
- Modify `tailwind.config.js` for custom color schemes
- Change DaisyUI theme in the config file
- Update component colors in individual files

### Content
- Edit page content in `/src/pages/` directory
- Update team information in About page
- Modify services and solutions in respective pages
- Change contact information in Contact page

### Styling
- Add custom CSS in `/src/index.css`
- Modify component styles using TailwindCSS classes
- Update animations in Framer Motion components
